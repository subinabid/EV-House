# EV House Family Tree

Interactive family tree web app built with Flask and D3.js. Data is sourced from a Google Sheet.

## Quick Start

```bash
# Install dependencies
pipenv install --dev
```

```bash
# Fetch latest data from Google Sheet
pipenv run python sheets.py
```

```bash
# Run the web app
pipenv run python app.py
# → http://localhost:4000
```

## Project Structure

```text
├── app.py              # Flask app (routes + API)
├── sheets.py           # Google Sheets → family_members.json
├── models.py           # Person model (parent/spouse/children graph)
├── tree_builder.py     # Flat data → D3 hierarchical tree
├── templates/
│   └── index.html      # Jinja template with D3.js
├── static/
│   ├── css/style.css
│   └── js/tree.js      # D3 interactive tree visualization
├── test_app.py         # Pytest unit tests
└── family_members.json # Cached data (generated by sheets.py)
```

## Features

- **Top-down tree** with interactive zoom, pan, and collapse/expand
- **Search** members by name — auto-expands and pans to result
- **Detail panel** — click any node to see full member info
- **Color-coded** by gender (blue = male, pink = female)
- **Spouses** shown as labels on their partner's card
- Full-width responsive layout

## Data Flow

Google Sheet  →  sheets.py  →  family_members.json  →  app.py  →  Browser

Run `pipenv run python sheets.py` whenever sheet data changes.
