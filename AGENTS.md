# Project Instructions

- This is a family free
- Written with flask
- Family information is fetched from a google sheet
- The information is dumped to a JSON file by a script
- The JSON is used by the app as data source
- The tree should be displayed form top to bottom
- Sl #1 in the sheet is the origin of the family
- Column M(Spouse) will give the serial number of the spouse. If this is populated, that indicates that this person married to the family
- Column L(Parent) will give the sl number of the parent. Children should be displayed under a parent
- For clarity, Sl #1 is Kachumma, the origin of the family
- Sl #2 is Mohammed Koya. His parent details is left blank and spouse sl is 1 (Kachumma)
- Sl#3 is Kalmabi with parent as 1 (Kachumma)
- Use full width of the screen for visualisation
- Use D3 for visualisation
- There should be a search option on the top
- There should be an area on the right to display details of the person selected
